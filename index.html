🧩 考生模型（只输出 SVG 代码）
SVG 模式：让考生模型输出一段可渲染的 SVG 代码，本地渲染 512×512 后截图送评审，不依赖中转站的图像生成链路，DeepSeek / GLM / Moonshot 等纯文本模型也能当考生。Token 预算（上限不是花费）：生成输出 ≤4000，被截断才升到 ≤8000；自评 ≤600、再审 ≤800、代码审阅 ≤400，超上限即失败止损。一份正常检测全程约 2000~3000 输出 token；推理模型把预算烧在思考上会提前失败止损，这正是要抓的「掺水」行为。考生不支持看图时自评退化为「代码审阅」；再审（考官）只看渲染出的图片打分，必须配支持视觉的模型。图片模式：需要真实的图像生成模型。
DeepSeek 官方已提供 Anthropic 兼容端点：Base 填 https://api.deepseek.com/anthropic 即可用 /v1/messages（该地址不提供 /models 列表，测试连接会跳过列表校验）；Moonshot / GLM / 通义等目前仍只有 OpenAI 兼容端点，请选「OpenAI 格式」。SVG 模式下该协议仅决定走哪个对话端点；「图片接口出图」模式才需要图像生成模型（gpt-image / seedream / flux 等）。
